⚖️ 1. So Sánh Mô Hình: Claude Desktop vs Telegram AI Gateway

Hệ thống Odoo MCP Server được thiết kế linh hoạt hỗ trợ 2 môi trường vận hành riêng biệt: Cổng Developer trực tiếp trên Claude Desktop App và Cổng Doanh nghiệp Bảo mật qua Telegram Bot.

🖥️ Claude Desktop App (Direct MCP)
  • Đối tượng: Developer, SysAdmin, Odoo Specialist.
  • Kết nối: Kết nối trực tiếp qua STDIO qua file claude_desktop_config.json.
  • Xác thực: Sử dụng tài khoản Odoo Admin cố định trong .env.
  • Giao diện: Hiển thị bảng biểu chi tiết, danh sách Tools loaded, tiến trình search_records, preview_write, validate_write trực quan.
  • Mục đích: Quản trị hệ thống, kiểm thử tool, phân tích dữ liệu chuyên sâu.
📱 Telegram AI Gateway (Zero-Trust Auth)
  • Đối tượng: Nhân viên Sale, Kho, Kế toán & Ban Quản lý.
  • Kết nối: Web Gateway FastAPI (Render Cloud) + Telegram Bot API.
  • Xác thực: Bắt buộc OTP Email 6 số (n8n Webhook) & đọc quyền LIVE Odoo (4 Roles).
  • Bảo mật: Tự động chặn đơn nháp > 20 triệu VNĐ (Approval Gate), sinh chữ ký số HMAC-SHA256 gửi nút bấm duyệt Telegram.
  • Mục đích: Vận hành kinh doanh di động 24/7.
