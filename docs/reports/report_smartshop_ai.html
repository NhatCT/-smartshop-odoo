1. Project Overview

The Smartshop Odoo AI Integration project establishes a secure, standard-compliant bridge connecting Claude Desktop AI Assistant directly with the Odoo SaaS Enterprise v19.4 backend. By implementing Anthropic's open Model Context Protocol (MCP), the integration empowers business analysts and executives to query real-time enterprise data, calculate KPIs, and manage inventory workflows using natural language.

The implementation strictly adheres to standard open-source libraries and protocols, avoiding custom-built reinvented logic to ensure zero technical debt, high reliability, and seamless upgrades.

2. System Architecture

The integration architecture follows a 4-tier decoupled model: AI Desktop Client, MCP Server, RPC Protocol Layer, and Cloud ERP Backend.

Figure 2.1: End-to-end data flow between AI Client, MCP Protocol Server, and Odoo SaaS Backend.

Core Architecture Layers

  1. AI Agent Client: Claude Desktop handles planning, prompt processing, and Markdown UI rendering.
  2. Protocol Transport: Standard JSON-RPC stdio transport ensuring clean separation of stdout data and stderr logging streams.
  3. MCP Server Layer: odoo-mcp (PyPI package) exposes 41 business-ready tools with built-in schema caching and gated write workflows.
  4. Odoo ERP Backend: Cloud-hosted Odoo Enterprise instance handling core business data and transactions via API Key authentication.

5. Enterprise Architecture & Improvement Plan

The technical improvement strategy transitions the system into a standardized Zero-Custom Infrastructure by assembling 5 industry-proven open-source "wheels" (Configuration Over Code):

Pillar Open-Source Tool Implementation Strategy & Value
Agent Orchestration LangGraph / CrewAI Orchestration engine providing State Machines, automatic RPC error retries, and sub-agent loops without writing custom logic.
Agent Skill System Open Agent Skills (npx skills / SKILL.md) Standardized business skill packaging (YAML/Markdown). Enables Just-In-Time skill loading without modifying source code.
Harness Guardrails LangGraph interrupts / FastMCP Native interrupt_before for sensitive actions (validate_write, action_apply_inventory) to enforce approval workflow.
Code Execution E2B Sandbox SDK Secure containerized Python execution environment for AI data analysis and Odoo data transformation without server risk.
Observability & Audit LangSmith / OpenTelemetry Direct SDK tracing for MCP tool latency, token cost metrics, and full audit logs on a visual dashboard without custom DB logging.
